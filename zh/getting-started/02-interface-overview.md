## 概述

睿阁采用 **左侧边栏 + 右侧内容区** 的经典 Web 应用布局，让你在一个界面中完成知识库管理、智能体配置、团队协作和对话问答等所有操作。

本篇将带你认识：

- 左侧边栏的组成与各菜单入口
- 用户信息区的位置与功能
- 右侧内容区如何根据菜单切换
- 新手引导的交互方式
- 全局搜索快捷键

读完本篇后，你将能够快速定位睿阁中的任意功能区域，知道"该去哪里做什么"。

## 前置条件

- 已完成 [访问与登录](/zh/getting-started/01-access-login)
- 建议先跟随新手引导走一遍核心区域

## 操作步骤

### 1. 认识整体布局

登录后，整个页面从左到右分为两个区域：

| 区域 | 默认宽度 | 主要职责 |
| --- | --- | --- |
| 左侧边栏 | 260 像素 | 知识库、智能体、团队、新对话菜单入口；历史会话列表；用户信息区 |
| 右侧内容区 | 自适应填充 | 根据选中菜单切换显示对应内容（知识库列表、智能体列表、对话页面等） |

> 提示：左侧边栏可通过顶部的「收起侧边栏」按钮折叠，折叠后可腾出更多空间给右侧内容区。再次点击可展开。

### 2. 左侧边栏

左侧边栏自上而下分为以下区域：

#### 2.1 顶部操作区

- **睿阁图标**：显示产品 Logo
- **搜索按钮**：点击打开全局搜索（快捷键 Ctrl+K）
- **新手引导**：点击可重新打开新手引导流程
- **收起侧边栏按钮**：点击折叠左侧边栏

#### 2.2 主导航菜单

| 菜单 | 图标 | 说明 |
| --- | --- | --- |
| 知识库 | 文档图标 | 点击进入知识库列表页，查看和管理所有知识库 |
| 智能体 | 星星图标 | 点击进入智能体列表页，查看和管理所有智能体 |
| 团队 | 团队图标 | 点击进入团队列表页，查看和管理所属团队 |
| 新对话 | 对话图标 | 点击进入新对话页面，选择智能体开始对话 |

#### 2.3 分割线

主导航菜单与历史会话列表之间的视觉分隔。

#### 2.4 历史会话列表

显示「我的对话」标签下方的所有历史会话，按日期分组展示：

| 分组 | 排序规则 |
| --- | --- |
| 已置顶 | 始终排在最前，按置顶时间降序 |
| 今天 | 按更新时间降序 |
| 昨天 | 按更新时间降序 |
| 近7天 | 按更新时间降序 |
| 近30天 | 按更新时间降序 |
| 去年 | 按更新时间降序 |
| 更早 | 按更新时间降序 |

每个会话显示标题（超长文本自动截断省略），置顶会话带置顶图标。右键点击会话可弹出操作菜单：

| 操作 | 说明 |
| --- | --- |
| 置顶/取消置顶 | 将会话固定在列表顶部或取消固定 |
| 修改标题 | 编辑会话标题，最大 80 字符 |
| 清空消息 | 清除该会话的所有消息 |
| 批量管理 | 进入批量选择模式，可勾选多条会话后批量删除 |
| 删除记录 | 删除该会话（红色文字，需二次确认） |

> 提示：空分组不会显示，如果某个时间段没有对话，对应的分组标签会自动隐藏。

### 3. 用户信息区

在左侧边栏底部，显示当前登录用户的信息区。

**折叠状态**显示：
- 用户头像
- 用户名称
- 隐藏和展开按钮

**展开状态**额外显示：
- 头像与名称
- 新手引导入口
- 工作空间名称和所有者
- **全部设置**按钮：点击打开设置模态弹窗
- **退出**按钮：点击退出登录，返回登录页

> 提示：全部设置弹窗中包含账户设置（常规设置、用户信息、修改密码）、企业设置（企业信息、管理员管理、消息管理）、模型设置（模型管理、Ollama）和数据与扩展设置（向量数据库引擎、解析引擎、存储引擎、网络搜索）等配置项。

### 4. 右侧内容区

右侧内容区根据左侧边栏选中的菜单自动切换显示：

| 选中菜单 | 右侧显示内容 |
| --- | --- |
| 知识库 | 知识库列表页，显示所有知识库（按"我创建的"和"本空间其他成员"分组） |
| 智能体 | 智能体列表页，显示所有智能体（按内置/自定义分组，响应式卡片布局） |
| 团队 | 团队列表页，显示所属团队信息 |
| 新对话 | 新对话页面，包含欢迎语、推荐问题和输入框 |
| 历史会话 | 对应会话的对话页面，显示历史消息记录 |

#### 4.1 新对话页面

点击「新对话」菜单进入新对话页面，界面包含：

- **欢迎语**：「你好，我是睿阁，让你的知识触手可及」
- **推荐问题区域**：标题「你可以这样问我」，展示最多 8 个推荐问题卡片，点击卡片可直接发送该问题。推荐问题会根据当前选中的智能体和关联知识库自动更新
- **输入框区域**：
  - **智能体模式切换**：左侧显示当前选中的智能体名称，点击可切换其他智能体
  - **网络搜索开关**：智能体启用时显示，控制是否联网搜索
  - **图片上传**：支持 jpg/png/gif/webp，最多 5 张
  - **附件上传**：支持拖拽，最多 5 个文件
  - **@提及**：点击展开提及选择器，支持提及知识库、文件、标签、技能
  - **模型选择器**：右侧下拉选择对话模型
  - **发送按钮**：输入内容后显示，点击或按 Enter 发送，Shift+Enter 换行

### 5. 新手引导

首次进入睿阁时，系统会自动弹出新手引导，采用**聚光灯 + 遮罩 + 浮动卡片**的交互模式：

- **全屏遮罩**：半透明遮罩覆盖整个页面
- **聚光灯高亮**：在目标元素处留出透明区域，配合品牌色边框和光晕
- **引导卡片**：340px 宽的浮窗，包含标题、描述、步骤进度和操作按钮

引导步骤共 6~7 步（根据用户角色动态增减）：

| 步骤 | 内容 |
| --- | --- |
| 1 | 欢迎使用睿阁 |
| 2 | 创建你的知识库（高亮知识库菜单） |
| 3 | 打造专属智能体（高亮智能体菜单，仅管理员可见） |
| 4 | 发起智能对话（高亮新对话菜单） |
| 5 | 账户与设置入口（高亮用户菜单） |
| 6 | 配置你的模型（高亮模型管理入口，仅管理员可见） |
| 7 | 一切就绪 |

操作方式：
- 点击「下一步」/「上一步」切换步骤
- 点击「跳过」退出引导
- 按 Esc 键跳过引导
- 按左右箭头键切换步骤

> 提示：完成引导后，可通过左侧边栏底部用户菜单中的「新手引导」入口重新打开。

## 进阶用法

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + K | 打开全局搜索（搜索对话和知识库内容） |

> 提示：macOS 用户请使用 Cmd + K。

### 折叠与展开侧边栏

| 操作 | 入口 | 效果 |
| --- | --- | --- |
| 折叠侧边栏 | 左侧边栏顶部的「收起侧边栏」按钮 | 隐藏左侧边栏，右侧内容区获得更多空间 |
| 展开侧边栏 | 折叠后页面左侧出现的「展开侧边栏」按钮 | 恢复显示左侧边栏 |

## 常见问题

### Q1：左侧边栏不见了怎么办？

可能是被折叠了。在页面左侧找「展开侧边栏」按钮（通常是一个向右的箭头图标），点击即可恢复显示。

### Q2：右侧内容区显示空白怎么办？

- 确认是否已选择左侧菜单中的某个入口（知识库、智能体等）
- 尝试刷新页面（F5）
- 如果问题持续，联系管理员检查服务状态

### Q3：推荐问题不显示或显示不正确怎么办？

推荐问题根据当前选中的智能体和关联知识库自动生成。如果智能体未关联知识库，可能无法生成推荐问题。请确认：

- 当前选中的智能体已关联知识库
- 知识库中已有文档且索引完成
- 点击推荐问题区域的刷新按钮重新获取

### Q4：如何重新打开新手引导？

三种方式：

1. 点击左侧边栏底部用户菜单中的「新手引导」
2. 按 Ctrl+K 打开全局搜索，搜索"新手引导"
3. 首次进入时自动弹出（完成后不再自动弹出）

### Q5：@提及功能支持哪些文件类型？

@提及支持文本类文件，包括知识库中的文档和标签。选中后，相关内容会作为上下文注入对话，帮助智能体更精准地回答问题。

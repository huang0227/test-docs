## 概述

睿阁是一款私有化部署的 Web 应用，通过浏览器访问即可使用，无需安装任何客户端。本篇介绍如何获取访问地址、完成登录，以及如何管理你的账户信息。

读完本篇后，你将能够顺利登录睿阁并管理自己的账号与会话。

## 前置条件

- 管理员已完成睿阁的私有化部署
- 管理员已为你创建账号并分配了访问权限
- 你已获取睿阁的访问地址（由管理员提供）
- 电脑已安装主流浏览器（推荐 Chrome、Edge）

## 操作步骤

### 1. 获取访问地址

联系你的系统管理员，获取睿阁的访问地址。地址格式通常为：

- 内网部署：`http://<服务器IP>:<端口>` 或 `https://<域名>`
- 例如：`http://192.168.1.100:8080` 或 `https://reknow.yourcompany.com`

> 提示：首次访问时，浏览器可能会提示"连接不安全"（HTTP 协议），这是因为内网部署未配置 SSL 证书。点击"高级 → 继续访问"即可，不影响正常使用。

### 2. 打开浏览器

使用 Chrome、Edge 等主流浏览器，在地址栏输入管理员提供的访问地址，按回车键打开。

### 3. 输入用户名和密码登录

在登录页面中：

1. 输入管理员分配的**用户名**
2. 输入对应的**密码**
3. 点击「登录」按钮

> 注意：密码需要满足 8~32 个字符，且包含字母和数字。

登录成功后，系统将自动跳转到主界面。

### 4. 登录后进入主界面

登录成功后，你将看到睿阁的主界面，包含：

- **左侧边栏**：知识库、智能体、团队、新对话等菜单入口
- **右侧内容区**：默认显示知识库列表页

> 提示：首次进入时，系统会自动弹出**新手引导**，通过聚光灯 + 遮罩 + 浮动卡片的方式，带你快速了解核心功能区域。你可以跟随引导完成初始了解，也可以点击"跳过"稍后通过用户菜单重新打开。

## 用户信息区

在左侧边栏底部，显示当前登录用户的信息区。点击用户信息区域可展开/折叠详细信息。

展开后显示以下内容：

| 项目 | 说明 |
| --- | --- |
| 头像 | 当前用户的头像 |
| 名称 | 当前用户的显示名称 |
| 新手引导 | 点击可重新打开新手引导 |
| 工作空间 | 当前所属工作空间的名称和所有者信息 |
| 全部设置 | 点击打开设置弹窗，可管理账户、企业、模型等配置 |
| 退出 | 点击退出当前登录，返回登录页 |

## 修改密码

1. 点击左侧边栏底部的用户信息区
2. 点击「全部设置」按钮
3. 在设置弹窗左侧导航中选择「账户 → 修改密码」
4. 输入当前密码、新密码、确认新密码
5. 点击「修改密码」按钮

> 注意：修改密码后，当前登录状态将失效，系统会自动退出并跳转到登录页，需要使用新密码重新登录。

密码要求：
- 长度 8~32 个字符
- 必须包含字母和数字

## 退出登录

1. 点击左侧边栏底部的用户信息区
2. 点击「退出」按钮
3. 系统将清除登录状态并返回登录页

> 提示：退出登录不会删除你的知识库、对话记录等数据。再次登录后可继续使用。

## 常见问题

### Q1：打开访问地址后显示空白页或无法连接怎么办？

可能原因与处理方式：

- **地址输入错误**：确认访问地址是否正确，注意端口号
- **服务器未启动**：联系管理员确认睿阁服务是否正常运行
- **网络不通**：确认你的电脑与服务器在同一网络，或 VPN 已连接
- **防火墙拦截**：确认服务器防火墙已开放对应端口

### Q2：登录时提示"用户名或密码错误"怎么办？

- 确认用户名和密码是否输入正确，注意大小写
- 如果忘记密码，请联系管理员重置密码
- 确认 Caps Lock 键是否误开启

### Q3：登录后页面一直加载中怎么办？

- 尝试刷新页面（F5）
- 清除浏览器缓存后重新访问
- 检查网络连接是否稳定
- 如果问题持续，联系管理员检查服务器状态

### Q4：如何修改用户名或邮箱？

用户名和邮箱为系统只读信息，无法自行修改。如需变更，请联系管理员在后台进行修改。

### Q5：密码修改后多久生效？

密码修改后立即生效。当前会话会被强制退出，需要使用新密码重新登录。

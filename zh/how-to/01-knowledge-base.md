## 概述

知识库是睿阁组织文档和知识的核心单元。每个知识库可以独立管理一组文档，支持文档型和 FAQ 问答型两种类型，并可配置不同的索引策略（RAG 检索、Wiki 知识库）。

知识库由团队成员共同维护，支持跨团队共享。本文介绍如何在知识库列表页完成知识库的浏览、创建、编辑和删除等基础操作。

读完本文你将能够：

- 浏览和筛选知识库列表
- 创建一个新的知识库
- 编辑已有知识库的基本信息
- 删除不再使用的知识库
- 理解知识库卡片上各标签的含义

---

## 前置条件

- 已登录睿阁，进入主工作区。
- 已完成至少一个模型的配置（创建知识库时需要选择 LLM 和 Embedding 模型），参见系统设置中的模型管理。
- 如需创建知识库，当前账号需要具备相应权限（企业创建者、企业管理员或团队管理员/编辑者）。

## 操作步骤

### 1. 知识库列表页

点击左侧侧边栏的「知识库」菜单，右侧显示知识库列表页。

#### 顶部区域

- **标题**：「知识库」，副标题为「管理和组织知识库，支持文档型和问答型知识库」。
- **新建知识库按钮**：位于标题右侧，点击后打开创建知识库弹窗。

#### 筛选标签

标题下方提供筛选标签，可快速过滤知识库：

| 标签 | 说明 |
| --- | --- |
| 全部 | 显示当前空间所有知识库，右侧显示总数 |
| 收藏 | 显示已收藏的知识库 |
| 最近 | 显示最近访问的知识库 |
| 团队名 | 按团队分组显示，右侧显示该团队下知识库数量 |

> 提示：当某类标签下数量为 0 时，数量不显示。

#### 列表区域

列表按分组展示知识库，每个分组可折叠：

- **我创建的**：当前用户创建的知识库列表，标题右侧显示数量。
- **本空间·其他成员**：其他成员创建的知识库列表，标题右侧显示数量。

### 2. 创建知识库

1. 在知识库列表页顶部，点击「新建知识库」按钮。
2. 弹出知识库设置弹窗，首先需要填写**基本信息**（详见 [知识库高级设置](/zh/how-to/02-knowledge-base-settings)）：
   - 选择知识库类型：文档 或 问答。
   - 选择索引策略：RAG 检索 或 Wiki 知识库（仅文档类型）。
   - 填写知识库名称（必填，最多 50 字）。
   - 填写知识库描述（可选，最多 200 字）。
3. 根据需要配置高级选项（模型、分块、解析引擎等），或使用默认配置直接创建。
4. 点击底部「创建」按钮完成创建。

> 提示：创建时系统会自动选择第一个默认模型作为 LLM 和 Embedding 模型，如需调整可在弹窗左侧导航的「高级配置」中修改。

### 3. 编辑知识库

1. 在知识库列表中，将鼠标悬停到目标知识库卡片上。
2. 点击卡片上的「设置」入口，打开知识库设置弹窗。
3. 在弹窗中修改各项配置，参见 [知识库高级设置](/zh/how-to/02-knowledge-base-settings)。
4. 修改完成后点击底部「保存」按钮。

> 注意：编辑模式下，知识库类型和部分已被文件使用的配置（如 Embedding 模型、索引策略、向量存储引擎）会被锁定不可修改。

### 4. 删除知识库

1. 在知识库设置弹窗中，找到删除入口。
2. 点击删除后，系统弹出二次确认对话框。
3. 确认删除后，知识库及其关联的文件数据将被永久移除。

> 注意：删除操作不可恢复，请谨慎操作。建议在删除前确认知识库中没有重要数据。

## 知识库卡片信息

每个知识库在列表中以卡片形式展示，包含以下信息：

| 信息项 | 说明 |
| --- | --- |
| 名称 | 知识库的名称 |
| 描述 | 知识库的简要描述，无描述时显示"暂无描述" |
| 创建者 | 创建该知识库的成员名称 |
| 标签 | 根据配置动态显示的功能标签（见下表） |

**功能标签说明**：

| 标签 | 显示条件 | 含义 |
| --- | --- | --- |
| 文件数量 | 始终显示 | 知识库中已导入的文档数量 |
| 知识图谱 | 启用了知识图谱提取 | 该知识库开启了实体关系提取功能 |
| 多模态 | 启用了多模态功能 | 该知识库支持图片内容解析 |
| 问题生成 | 启用了 AI 问题生成 | 系统会为文档自动生成索引问题 |
| 已共享给 x 个空间 | 已共享到其他团队 | 知识库已被共享到指定数量的团队 |

## 进阶用法

### 收藏知识库

在知识库卡片上点击收藏按钮（星标图标），可将常用知识库标记为收藏。收藏后可通过筛选标签中的「收藏」快速找到。

### 批量管理

当知识库数量较多时，善用顶部筛选标签（全部/收藏/最近/团队名）快速定位目标知识库。

## 常见问题

### Q1：创建知识库时提示模型未配置怎么办？

创建知识库需要至少配置一个 LLM 模型和一个 Embedding 模型。请前往系统设置的模型管理页面添加模型后再创建知识库。

### Q2：知识库类型选错了可以修改吗？

知识库类型（文档/问答）在创建后不可修改。如需更改类型，请新建一个正确类型的知识库，将原有数据迁移后删除旧知识库。

### Q3：为什么有些配置项在编辑时显示锁定？

编辑模式下，已被文件使用的配置（如 Embedding 模型、索引策略、向量存储引擎）会被锁定，以避免已有索引数据不一致。如需变更这些配置，需要先删除知识库中的文件。

### Q4：删除知识库后文件还能恢复吗？

不能。删除知识库会永久移除其关联的所有文件和索引数据，操作前请确认数据已备份。

### Q5：本空间·其他成员的知识库我能编辑吗？

可以编辑的前提是你被该知识库共享到了对应团队，且共享权限为编辑权限。否则只能浏览不能修改。

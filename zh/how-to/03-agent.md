## 概述

智能体是睿阁的对话引擎，负责根据知识库内容和配置的提示词回答用户问题。每个智能体可以独立配置运行模式、关联知识库、设置提示词和选择模型，满足不同业务场景的需求。

睿阁提供两种运行模式的智能体：**快速问答**（基础 RAG 问答，快速响应）和**智能推理**（Agent 模式，支持多步推理和工具调用）。本文介绍如何在智能体列表页完成智能体的浏览、创建、编辑、复制、停用和删除等操作。

读完本文你将能够：

- 浏览和筛选智能体列表
- 创建和编辑智能体
- 复制、停用、启用或删除智能体
- 收藏常用智能体
- 理解智能体卡片上各功能徽章的含义

---

## 前置条件

- 已登录睿阁，进入主工作区。
- 已完成至少一个模型的配置（创建智能体时需要选择模型）。
- 创建智能体需要企业创建者或企业管理员角色；普通成员可浏览和使用已配置的智能体。

---

## 操作步骤

### 1. 智能体列表页

点击左侧侧边栏的「智能体」菜单，进入智能体列表页。

#### 顶部区域

- **页面标题**：「智能体」
- **副标题**：根据角色显示不同文案
  - 企业创建者/企业管理员：「配置和管理智能体，自定义对话行为和能力」
  - 普通成员：「浏览并使用为您配置的智能体，快速开启智能对话」
- **创建按钮**：带星星图标，仅企业创建者和企业管理员可见。

#### 筛选标签

| 标签 | 说明 |
| --- | --- |
| 全部 | 显示所有智能体，默认选中 |
| 收藏 | 显示已收藏的智能体 |
| 最近 | 显示最近使用的智能体 |

> 提示：当某类标签下数量为 0 时，数量不显示。

#### 分组展示

智能体按分组展示，每个分组可折叠（点击分组标题展开/收起）。使用响应式网格布局，根据屏幕宽度自动调整列数。

| 分组 | 说明 | 可见角色 |
| --- | --- | --- |
| 内置智能体 | 系统预置的智能体，始终置顶显示 | 所有人 |
| 企业智能体 | 所有非内置智能体的汇总 | 普通成员 |
| 我创建的 | 当前用户创建的智能体 | 企业创建者/管理员 |
| 本空间·其他成员 | 其他成员创建的智能体 | 企业创建者/管理员 |

### 2. 创建智能体

1. 在智能体列表页顶部，点击「创建」按钮（带星星图标）。
2. 打开全屏模态弹窗编辑器，首先进入「基本信息」配置：
   - 选择**运行模式**：快速问答 或 智能推理。
   - 填写智能体名称和描述。
   - 如选择智能推理模式，可选择**智能体类型预设**（RAG 问答、Wiki 问答、Wiki + RAG 混合、数据分析、自定义）。
3. 根据需要配置提示词、模型、知识库、检索策略等选项，详见 [智能体高级设置](/zh/how-to/04-agent-settings)。
4. 点击底部「保存」按钮完成创建。

> 提示：选择智能体类型预设后，系统会自动配置对应的提示词、工具和模型参数，减少手动配置工作。

### 3. 编辑智能体

1. 在智能体卡片上，鼠标悬停后点击右上角的「更多操作」菜单（三点图标）。
2. 选择「编辑」，打开全屏模态弹窗编辑器。
3. 修改各项配置后点击底部「保存」按钮。

> 提示：「编辑」选项仅对智能体创建者或企业管理员可见。

### 4. 复制智能体

1. 在智能体卡片上，鼠标悬停后点击右上角的「更多操作」菜单。
2. 选择「复制」，系统将基于当前智能体的配置创建一个副本。

> 提示：「复制」选项仅对企业创建者或企业管理员可见。复制的智能体会保留原智能体的所有配置。

### 5. 停用 / 启用智能体

1. 在智能体卡片上，鼠标悬停后点击右上角的「更多操作」菜单。
2. 选择「停用」或「启用」切换智能体的可用状态。

> 提示：「停用/启用」选项仅对企业管理员可见。停用后智能体卡片上会显示「已停用」标签，用户将无法与该智能体对话。

### 6. 删除智能体

1. 在智能体卡片上，鼠标悬停后点击右上角的「更多操作」菜单。
2. 选择「删除」，系统弹出二次确认对话框。
3. 确认删除后，智能体将被永久移除。

> 注意：内置智能体不可删除。删除操作仅对智能体创建者或企业管理员可见，且不可恢复。

### 7. 收藏智能体

- 在智能体卡片右上角，鼠标悬停时显示收藏按钮（星标图标）。
- 点击星标切换收藏状态：空心为未收藏，实心为已收藏。
- 已收藏的智能体始终显示实心星标。
- 收藏后可通过筛选标签中的「收藏」快速找到。

## 智能体卡片信息

每个智能体在列表中以卡片形式展示（固定高度 136px），包含以下信息：

| 信息项 | 说明 |
| --- | --- |
| 头像 | 内置智能体显示系统图标，自定义智能体显示 emoji 或首字母渐变色头像 |
| 名称 | 智能体名称，超长时截断显示 |
| 描述 | 智能体功能描述，最多 2 行，无描述时显示"暂无描述" |
| 更多操作菜单 | 鼠标悬停时显示，根据权限展示不同操作项 |

**功能徽章**（根据配置动态显示在卡片底部）：

| 徽章 | 显示条件 | 含义 |
| --- | --- | --- |
| 运行模式 | 始终显示 | 快速回答 或 智能推理 |
| 联网搜索 | 启用了联网搜索 | 智能体可搜索互联网获取信息 |
| 知识库 | 关联了知识库或选择了全部知识库 | 智能体可检索知识库内容 |
| MCP 服务 | 关联了 MCP 服务 | 智能体可调用 MCP 工具服务 |
| 多轮对话 | 快速回答模式下 multi_turn_enabled 为 true；智能推理模式下数据库字段为 true 时显示 | 支持上下文连续对话 |
| 已停用 | disabled_by_me 为 true | 该智能体已被停用 |

## 进阶用法

### 智能体类型预设选择建议

创建智能体时选择智能推理模式后，可从以下预设中快速开始：

| 预设 | 适用场景 | 自动配置 |
| --- | --- | --- |
| RAG 问答 | 基于文档分块的检索式问答，适合未启用 Wiki 的文档/FAQ 知识库 | 提示词、知识库检索工具、温度 0.7、最大迭代 30 |
| Wiki 问答 | 以 Wiki 为主的检索与图谱跳转回答，必须绑定已启用 Wiki 的知识库 | 提示词、Wiki 工具集、温度 0.7、最大迭代 30 |
| Wiki + RAG 混合 | 先用 Wiki 建立导航和背景，再用分块检索精确引用 | 提示词、Wiki + RAG 工具集、温度 0.7、最大迭代 40 |
| 数据分析 | 对 CSV/Excel 等表格文件执行 SQL 查询和统计分析 | 提示词、数据分析工具、温度 0.3、最大迭代 30 |
| 自定义 | 完全自定义配置 | 无自动配置 |

### 快速问答 vs 智能推理

| 对比项 | 快速问答 | 智能推理 |
| --- | --- | --- |
| 核心能力 | 基础 RAG 问答，强调知识库检索 + 提示词控制 | Agent 模式，支持工具调用、多步推理、反思 |
| 响应速度 | 快速 | 较慢（需要多步推理） |
| 工具支持 | 不支持工具调用 | 支持多种工具（搜索、Wiki、数据分析等） |
| 多轮对话 | 可选（需手动开启） | 始终支持（后端强制启用） |
| 适用场景 | 常见问题问答、客服机器人 | 复杂研究、深度分析、多步骤任务 |

## 常见问题

### Q1：为什么我看不到「创建」按钮？

创建智能体需要企业创建者或企业管理员角色。普通成员只能浏览和使用已配置的智能体，如需创建请联系管理员调整角色权限。

### Q2：内置智能体可以编辑吗？

内置智能体的部分配置可以修改（如提示词），但不可删除或停用。内置智能体始终置顶显示在列表中。

### Q3：复制的智能体和原智能体有什么关系？

复制的智能体是一个独立的副本，拥有全新的 ID 和独立的配置。修改副本不会影响原智能体，反之亦然。

### Q4：停用智能体后用户还能看到吗？

停用后智能体卡片上会显示「已停用」标签，用户无法与该智能体发起新对话。但管理员仍可在列表中看到并重新启用。

### Q5：智能推理模式下的智能体类型预设可以更换吗？

可以。在编辑模式下重新选择预设即可，系统会自动更新对应的配置。但需注意，更换预设可能会覆盖已有的自定义配置。

### Q6：为什么有些智能体我看不到？

智能体的可见性取决于分组：普通成员只能看到「内置智能体」和「企业智能体」分组；企业创建者/管理员可以看到所有分组。如果智能体被停用，所有用户仍可在列表中看到但无法使用。

## 概述

对话是睿阁的核心交互方式。你通过对话向智能体提问，智能体结合知识库、网络搜索等能力为你提供精准回答。本文介绍如何新建对话、使用输入框功能、管理历史会话，以及@提及等进阶用法。

读完本文你将能够：

- 创建新对话并发送消息。
- 切换智能体、选择模型、上传图片和附件。
- 管理历史会话：置顶、重命名、清空、批量删除。
- 使用@提及引用知识库、文件、标签和 Skill。

---

## 前置条件

- 已登录睿阁并进入主工作区。
- 系统中至少配置了一个可用的对话模型（管理员在[全局设置](/zh/reference/04-settings)中配置）。

---

## 操作步骤

### 1. 新对话页面

点击左侧侧边栏的「新对话」菜单，进入新对话页面。

**欢迎语区域**：居中显示「你好，我是睿阁，让你的知识触手可及」。

**推荐问题区域**：
- 标题「你可以这样问我」，右侧有刷新按钮可重新获取推荐问题。
- 最多展示 8 个推荐问题卡片，点击即可直接发送该问题。
- 推荐问题会根据当前选中的智能体、知识库、文件、标签和 Skill 自动更新。

### 2. 输入框区域

输入框位于页面底部，支持以下功能：

**左侧控制栏**：

| 功能 | 说明 |
|------|------|
| 智能体切换 | 显示当前智能体名称（默认「智能推理」），点击展开智能体选择器 |
| 网络搜索开关 | 智能体启用时显示，控制是否在回答时检索互联网信息 |
| 图片上传 | 仅智能体支持图片时显示，支持 jpg/png/gif/webp，最多 5 张 |
| 附件上传 | 回形针图标，最多 5 个文件，支持拖拽上传 |
| @提及 | 引用知识库、文件、标签或 Skill，详见[进阶用法](#提及) |

**右侧控制栏**：
- **模型选择器**：下拉选择对话模型，管理员可在此添加新模型。
- **发送按钮**：有内容时高亮显示，点击或按 Enter 发送，Shift+Enter 换行。

### 3. 选择智能体

点击智能体切换按钮，展开智能体选择器面板：

- **顶部操作栏**：管理员显示「+ 管理」按钮跳转智能体列表；普通成员显示「浏览 查看」按钮。
- **智能体分组**：
  - 内置智能体：所有人可见。
  - 自定义智能体：显示所有未停用的自定义智能体。
- **智能体详情浮窗**：鼠标悬停某智能体时，右侧显示详情浮窗，包含：
  - 头像、名称、描述
  - 运行模式（智能推理 / 快速问答）
  - 知识库能力（可访问全部 / 指定数量）
  - MCP 能力
  - 网络搜索、图片上传支持状态
  - 设置按钮（管理员可见）

> 注意：如果智能体显示「未就绪」状态（如缺少对话模型或重排模型），则无法选择该智能体进行对话。管理员可点击设置按钮跳转配置页面。

### 4. 历史会话列表

左侧侧边栏「新对话」菜单下方是历史会话列表区域，按日期分组展示：

| 分组 | 排序规则 |
|------|---------|
| 已置顶 | 按置顶时间降序 |
| 今天 | 按更新时间降序 |
| 昨天 | 按更新时间降序 |
| 近 7 天 | 按更新时间降序 |
| 近 30 天 | 按更新时间降序 |
| 近 1 年 | 按更新时间降序 |
| 更早 | 按更新时间降序 |

每个会话行显示标题（超长截断，最大 80 字符，由对话模型自动生成）。置顶会话显示图钉图标，当前激活的会话高亮显示。

### 5. 会话操作

鼠标悬停会话行后，可通过右键菜单执行以下操作：

| 操作 | 说明 |
|------|------|
| 置顶/取消置顶 | 将会话固定到列表顶部或取消固定 |
| 修改标题 | 进入编辑模式，输入新标题后按 Enter 保存 |
| 清空消息 | 清除会话中的所有消息 |
| 批量管理 | 进入批量选择模式，勾选多个会话后批量删除 |
| 删除记录 | 删除单条会话（红色文字，需确认） |

**批量管理模式**：
1. 在右键菜单中选择「批量管理」。
2. 每行左侧出现复选框，点击整行或复选框可切换选中状态。
3. 底部操作栏显示全选复选框、取消按钮和删除按钮（显示已选数量）。

### 6. 消息发送

- 按 **Enter** 发送消息。
- 按 **Shift+Enter** 换行。
- 输入框支持拖拽文件上传附件。

## 进阶用法

### @提及

在输入框中输入 `@` 触发提及选择器，可引用以下内容：

| 类型 | 说明 |
|------|------|
| 知识库 | 引用整个知识库，智能体将在该知识库范围内检索回答 |
| 文件 | 引用知识库中的特定文件 |
| 标签 | 按标签筛选知识库内容 |
| Skill | 引用特定的智能体技能 |

@提及的内容会作为上下文传递给智能体，帮助其更精准地理解你的问题。

### 切换智能体后推荐问题的变化

切换智能体后，推荐问题区域会自动更新为该智能体关联的问题。推荐问题还会根据已选的知识库、文件、标签和 Skill 动态调整。

## 常见问题

### Q1：新对话为什么不立刻出现在侧边栏列表里？

新对话在发送第一条消息前不会真正创建记录。发送消息后，对话会自动生成并以首条消息摘要作为默认标题，此时才会出现在列表中。

### Q2：对话标题能修改吗？

可以。右键点击会话行选择「修改标题」，或在聊天区顶部直接点击标题编辑。标题最大 80 个字符。

### Q3：删除会话后还能找回吗？

删除会话是不可恢复的操作，删除后该会话及其所有消息将永久丢失。删除前请仔细核对。

### Q4：为什么有些智能体无法选择？

如果智能体显示「未就绪」状态，说明该智能体缺少必要配置（如对话模型或重排模型）。请联系管理员在智能体设置中补充配置。

### Q5：推荐问题为什么不显示？

推荐问题依赖智能体配置。如果当前智能体未设置推荐问题，或智能体未就绪，推荐问题区域将不会显示。

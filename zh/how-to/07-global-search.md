## 概述

全局搜索是睿阁的统一检索入口，帮助你快速定位知识库文件、对话消息、智能体、团队和系统命令。通过键盘快捷键即可随时唤起搜索面板，无需在各页面间来回切换。

读完本文你将能够：

- 使用快捷键打开全局搜索并快速定位资源。
- 了解搜索结果的分组方式和交互操作。
- 配置检索参数优化搜索精度。
- 使用快捷操作快速新建对话、打开知识库等。

---

## 前置条件

- 已登录睿阁并进入主工作区。

## 操作步骤

### 1. 打开全局搜索

使用以下任一方式打开搜索面板：

| 快捷键 | 说明 |
|--------|------|
| **Ctrl+K**（Mac: Cmd+K） | 随时打开搜索面板 |
| **/** 键 | 在无输入焦点时按 `/` 打开 |

搜索面板宽度 640px，距顶部 10vh，最大高度 60vh，搜索框自动聚焦。

### 2. 搜索输入框

- **搜索图标 + 输入框**：默认提示「搜索知识库、文件、对话...」。
- **知识库范围标签**：在知识库详情页打开搜索时自动限定搜索范围，点击 ✕ 可移除限定。
- **检索设置按钮**（齿轮图标）：点击打开检索设置抽屉，调整搜索参数。
- **关闭按钮**：关闭搜索面板。

### 3. 空状态（未输入搜索词）

未输入搜索词时，面板显示：

**最近搜索**：显示历史搜索记录，点击填充到搜索框，支持清除历史记录。

**快捷操作**（每项右侧显示快捷键提示）：

| 快捷操作 | 快捷键 | 说明 |
|---------|--------|------|
| 新建对话 | ⌘1 | 跳转到新对话页面 |
| 打开知识库 | ⌘2 | 跳转到知识库列表页 |
| 打开智能体 | ⌘3 | 跳转到智能体列表页 |
| 打开团队 | ⌘4 | 跳转到团队列表页（仅企业管理员可见） |
| 打开设置 | ⌘5 | 跳转到设置页面 |
| 新手引导 | ⌘6 | 打开新手引导 |

> 提示：⌘ 在 Mac 上对应 Command 键，在 Windows 上对应 Ctrl 键。

### 4. 搜索结果

输入搜索词后，结果按以下分组顺序展示（无结果的分组不显示）：

| 分组 | 每项显示内容 | 最多展示 |
|------|-------------|---------|
| 知识库文件 | 文件名 + 知识库名称标签 + 匹配类型（向量/关键字）+ 匹配片段 + 相关度分数 | 5 条 |
| 对话消息 | 会话标题 + Q/A 标记 + 匹配内容 + 相关度分数 | 4 条 |
| 知识库 | 知识库名称 | 4 条 |
| 智能体 | 智能体名称 + 描述 | 5 条 |
| 对话（按标题） | 会话标题 | 5 条 |
| 命令 | 命令名称 | 全部 |

> 注意：「对话（按标题）」与「对话消息」分组会自动去重，已出现在消息分组的会话不再重复显示。

### 5. 搜索结果交互

| 操作 | 效果 |
|------|------|
| 点击/回车 | 打开对应资源（知识块→知识库详情、消息→对话详情、智能体→新建对话、会话→对话详情、命令→执行操作） |
| ⌘+回车 | 对知识块结果，快速发起带预填内容的新对话 |
| ⌘+1~9 | 快速跳转到第 N 个结果 |
| ↑↓ | 键盘导航选择结果 |
| Esc | 关闭面板 |

### 6. 知识库范围限定

在知识库详情页打开搜索时，搜索范围自动限定为当前知识库：
- 搜索框下方显示范围标签（scope chip）。
- 点击 ✕ 可移除限定，切换为全局搜索。
- 限定范围时仅显示知识块搜索结果。

### 7. 无结果状态

当搜索无匹配结果时：
- 显示「没有找到匹配结果」提示。
- 提供「直接向 AI 提问」按钮：发起带预填内容的新对话。
- 提供「调整检索参数」按钮：打开检索设置抽屉。

## 进阶用法

### 检索设置

点击搜索框右侧的齿轮图标，打开检索设置抽屉（宽度 420px），可调整以下参数：

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| Rerank 模型 | 结果重排序模型（必填） | — | 下拉选择 |
| 向量检索数量（Top K） | 向量检索返回的最大结果数 | 50 | 1-100 |
| 向量相似度阈值 | 向量检索的最低相似度 | 0.15 | 0-1 |
| 关键词匹配阈值 | 关键词检索的最低匹配度 | 0.3 | 0-1 |
| Rerank 数量（Top K） | 重排序后保留的结果数 | 10 | 1-100 |
| Rerank 阈值 | 重排序的最低分数 | 0.20 | -10 到 10 |

参数修改后自动保存（500ms 防抖）。企业管理员和创建者可在选择 Rerank 模型时点击「前往全局设置添加模型」按钮。

> 提示：调高向量相似度阈值和关键词匹配阈值可以减少噪音结果，但也可能遗漏相关内容。建议根据实际搜索效果逐步调整。

## 常见问题

### Q1：为什么按 `/` 键没有打开搜索面板？

`/` 键仅在页面无输入框获得焦点时生效。如果当前光标在某个输入框中，请使用 Ctrl+K（Mac: Cmd+K）打开搜索。

### Q2：搜索结果中的「向量」和「关键字」是什么意思？

这是知识库文件的两种匹配方式：
- **向量**：通过语义相似度匹配，即使关键词不完全一致也能找到相关内容。
- **关键字**：通过精确关键词匹配，适合查找特定术语或编号。

### Q3：如何只搜索当前知识库的内容？

在知识库详情页打开搜索时，系统会自动限定搜索范围为当前知识库。搜索框下方会显示范围标签，点击 ✕ 可切换为全局搜索。

### Q4：搜索历史记录可以清除吗？

可以。在空状态页面的「最近搜索」区域，点击清除按钮即可清除所有历史搜索记录。

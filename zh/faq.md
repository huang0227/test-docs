## 知识库相关

### Q1：上传图片后只显示文件，没有摘要内容怎么办？

**原因**：MinerU 负责提取文档文本和识别图片，但图片描述需要多模态大模型（VLM）生成。如果没有配置 VLM 模型，图片只显示为文件引用，内容为空。

**解决方案**：
1. 检查是否配置了多模态大模型且可用。
2. 尝试切换为 MinerU Cloud 解析。
3. 更换为其他多模态大模型（如 mimo-v2.5、qwen3.5）。

### Q2：MinerU Cloud 解析失败怎么办？

**常见原因**：
- 文档超过 200 页限制。
- 文件超过 10MB 限制。

**解决方案**：切换为自部署 MinerU 或 PaddleOCR-VL Cloud。部分文档在 MinerU Cloud 解析失败时，PaddleOCR-VL Cloud 可能成功。

### Q3：复杂 PDF 文档如何选择解析引擎？

| 文档类型 | 推荐引擎 | 配置建议 |
|---------|---------|---------|
| 学术论文/技术文档 | MinerU | 启用公式识别、表格识别 |
| 财务报表/合同 | PaddleOCR-VL Cloud | 启用印章识别、图表识别 |
| 扫描件/图片 PDF | MinerU 或 PaddleOCR-VL Cloud | 启用 OCR，设置正确的语言 |
| 混合内容文档 | MinerU | 使用 hybrid-auto-engine |

### Q4：知识内容被强制分割怎么办？

部分内容（如大表格）超过最大分块大小后会被强制分割。临时解决方案：调大分块大小以避免被分割。

> 注意：系统硬编码了最大保护大小（7500 字符），超过此大小的表格会被强制分割，无法通过配置修改。

### Q5：.doc 文档解析失败怎么办？

尝试将 .doc 文件另存为一份新的 .doc 文档，再重新上传解析。重新保存可解决部分格式兼容问题。

### Q6：知识入库很慢，如何优化？

知识入库包含文档解析、多模态处理、摘要生成、问题生成、知识图谱提取、向量化索引等多个阶段。

**优化建议**：

| 优化方向 | 建议 | 效果 |
|---------|------|------|
| 增大任务队列并发 | 调整 asynq.concurrency 为 32-64 | 提升整体处理速度 |
| 减少问题生成数量 | 设置为 3-5 个 | 减少 LLM 调用次数 |
| 增大分块大小 | 设置为 1024-2048 | 减少分块数量 |
| 选择更快的 LLM 模型 | 使用 flash 模型 | 加速摘要和问题生成 |
| 关闭不需要的功能 | 关闭知识图谱等 | 减少后处理任务 |
| 关闭图像多模态 | 在知识库设置中关闭 | 跳过图片处理阶段 |

### Q7：CSV 文件解析后切片信息显示乱码怎么办？

**原因**：文件编码解析问题。

**解决方案**：保存 CSV 文件时使用 UTF-8 + BOM 编码方式，然后重新上传。

### Q8：知识库共享后如何设置只读？

在团队设置 → 成员管理中，将对应成员的角色设置为「只读」。

### Q9：添加模型时报错「Base URL 未通过安全校验」/ SSRF validation failed

**根本原因**：ReKnow-Core 内置 SSRF 安全校验，添加模型时会验证 Base URL 的 DNS 解析是否指向安全 IP。

**解决方案**：在 engine 容器的环境变量中添加 `SSRF_WHITELIST_EXTRA`，将模型服务域名加入白名单（逗号分隔）：

```yaml
environment:
  - SSRF_WHITELIST_EXTRA=litellm.bianjie.ai,dashscope.aliyuncs.com,api.openai.com
```

**常用白名单域名**：

| 域名 | 说明 |
|------|------|
| litellm.bianjie.ai | 边界智能 LiteLLM 代理 |
| dashscope.aliyuncs.com | 阿里通义千问 API |
| api.openai.com | OpenAI API |
| api.deepseek.com | DeepSeek API |

> 注意：IP 地址默认被拦截，必须显式加入白名单。修改后需重启 engine 容器生效。

## 智能体相关

### Q1：智能体显示「未就绪」无法选择怎么办？

智能体未就绪的常见原因：
- 缺少对话模型：未选择对话模型，或选择的模型不可用。
- 缺少重排模型：智能推理模式下启用知识库搜索但未选择重排模型。

**解决方案**：联系管理员在智能体设置中补充配置。

### Q2：如何切换对话使用的智能体？

在新对话页面的输入框左侧，点击智能体名称按钮展开选择器，选择其他智能体即可。切换后推荐问题会自动更新。

## 对话相关

### Q1：新对话为什么不立刻出现在侧边栏列表里？

新对话在发送第一条消息前不会真正创建记录。发送消息后，对话会自动生成并出现在列表中。

### Q2：对话标题能修改吗？

可以。右键点击会话行选择「修改标题」，标题最大 80 个字符。

### Q3：删除会话后还能找回吗？

不能。删除会话是不可恢复的操作，删除前请仔细核对。

## 团队相关

### Q1：普通成员能创建团队吗？

不能。只有企业创建者和企业管理员可以创建团队。普通成员只能通过邀请码或搜索方式加入已有团队。

### Q2：邀请码过期了怎么办？

联系团队管理员在团队设置中刷新邀请码，或让管理员直接添加您为成员。

### Q3：团队成员数量上限在哪里设置？

在团队设置 → 基本信息 → 成员数量上限处设置。设为 0 表示不限制。

## 模型配置相关

### Q1：如何选择对话模型？

| 优先级 | 推荐模型 | 说明 |
|--------|---------|------|
| 效果优先 | qwen3.5-397B-A17B | 精度最高、多模态 |
| 速度优先 | mimo-v2.5 | 速度快、性价比高 |
| 成本优先 | deepseek-v4-flash | 轻量快速 |
| 本地部署 | qwen3.5-122B-A10B INT4 | 单卡可跑、一模多用 |

### Q2：Embedding 模型可以更换吗？

知识库创建后，如果已有文件入库，Embedding 模型将锁定不可修改。如需更换，需删除已有索引数据后重新配置。

### Q3：Ollama 本地模型如何使用？

在全局设置 → Ollama 中检测本地服务状态，下载所需模型后，在模型管理中选择来源为「local(Ollama 本地)」添加模型。

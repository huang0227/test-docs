## 概述

智能体是睿阁的对话引擎。它决定了用户提问时系统如何理解问题、检索知识、组织回答。每个智能体由运行模式、提示词、模型、知识库、工具和检索策略等配置组合而成，不同的组合方式会产生截然不同的对话体验。

读完本文你将了解：

- 快速问答和智能推理两种运行模式的区别与适用场景。
- 智能体类型预设如何帮助快速搭建专业对话助手。
- 工具体系和技能（Skills）如何扩展智能体的能力边界。
- 检索策略和联网搜索的工作原理。

## 前置条件

- 已登录睿阁并进入主工作区。
- 建议先阅读 [知识库](/zh/concepts/01-knowledge-base) 了解知识库的基本概念，本文假设您已了解知识库的分块与检索原理。

## 运行模式

智能体支持两种运行模式，创建时需选择其一：

| 模式 | 说明 | 特点 |
| --- | --- | --- |
| 快速问答 | 基础 RAG 问答，无工具调用 | 强调知识库检索 + 提示词控制，响应速度快 |
| 智能推理 | Agent 模式 | 支持工具调用、多步推理、反思、Skills 等高级能力，适合复杂问题 |

### 快速问答模式

快速问答模式的工作流程：

1. 用户提问 → 系统自动检索知识库。
2. 检索到的内容按上下文模板格式化后注入对话。
3. 大语言模型基于系统提示词 + 检索上下文生成回答。

该模式适合大多数知识库问答场景，响应速度快、配置简单。支持以下专属配置：

- **上下文模板**：控制检索到的知识库内容如何格式化后传递给模型。
- **意图提示词**：针对不同用户意图（问候、闲聊、追问等）使用专门的提示词。
- **多轮对话**：开启后保留历史对话上下文，支持问题改写以消解指代和省略。
- **检索兜底**：当知识库检索无结果时，可选择固定回复或让模型自行生成回答。

### 智能推理模式

智能推理模式的工作流程：

1. 用户提问 → 智能体分析问题并制定计划。
2. 智能体按计划逐步调用工具（知识库检索、Wiki 查询、数据分析等）获取信息。
3. 智能体根据获取的信息进行推理和反思，必要时调整计划。
4. 综合所有信息生成最终回答。

该模式支持更多高级能力：

- **工具调用**：智能体可以主动选择和调用多种工具获取信息。
- **多步推理**：面对复杂问题，智能体可以分步骤逐步解决。
- **反思能力**：智能体可以评估自己的回答质量，必要时重新检索或补充信息。
- **Skills 加载**：按需加载专业领域的技能模块。

> 提示：智能推理模式始终支持多轮对话（后端强制启用），无需手动开启。

## 智能体类型预设

在智能推理模式下，睿阁提供了多种预设类型，帮助您快速创建特定场景的智能体：

| 预设 | 说明 | 自动配置的工具 | 适用场景 |
| --- | --- | --- | --- |
| RAG 问答 | 基于文档分块的检索式问答 | 语义搜索、关键词搜索、查看文档分块、获取文档信息 | 未启用 Wiki 的文档/FAQ 知识库 |
| Wiki 问答 | 以 Wiki 为主的检索与图谱跳转 | 搜索 Wiki、阅读 Wiki 页面、精读源文档、标记 Wiki 问题 | 已启用 Wiki 的知识库 |
| Wiki + RAG 混合 | 先用 Wiki 建立导航，再用分块检索精确引用 | 上述两类工具的组合 | 同时启用 Wiki 与向量/关键词索引的知识库 |
| 数据分析 | 对表格文件执行 SQL 查询和统计分析 | 数据分析、查看数据元信息 | 包含 CSV/Excel 文件的知识库 |
| 自定义 | 完全自定义工具、提示词和知识库 | 无自动配置 | 需要完全自定义的场景 |

> 提示：选择预设后，系统会自动配置对应的提示词、工具和参数。您可以在自动配置的基础上进一步调整。

## 工具体系

工具是智能推理模式下智能体与外部世界交互的能力接口。智能体在对话过程中可以主动选择和调用工具来获取信息、执行操作。

### 基础工具

| 工具 | 说明 |
| --- | --- |
| 思考 | 让模型在回答前进行内部思考，提高复杂问题的回答质量 |
| 制定计划 | 创建结构化的研究计划，跟踪任务进度，适合多步骤任务 |

### 知识库检索工具（RAG）

| 工具 | 说明 |
| --- | --- |
| 语义搜索 | 理解问题语义，查找相关内容，适合用户问题模糊的场景 |
| 关键词搜索 | 基于精确关键词快速定位文档，适合已知关键词的场景 |
| 查看文档分块 | 获取文档完整分块内容，了解知识库内容组织 |
| 查询知识图谱 | 利用知识图谱的结构化关系进行深度查询 |
| 获取文档信息 | 查看文档元数据（来源、创建时间、作者等） |
| 查询数据库 | 直接查询数据库，获取精确的结构化数据 |

### Wiki 工具

| 工具 | 说明 | 操作类型 |
| --- | --- | --- |
| 搜索 Wiki | 在 Wiki 知识库中按关键词/语义搜索页面 | 读取 |
| 阅读 Wiki 页面 | 读取指定 Wiki 页面的完整内容 | 读取 |
| 精读源文档 | 从 Wiki 知识点跳转到原始文档 | 读取 |
| 标记 Wiki 问题 | 标记页面中的事实错误或合并冲突 | 读取 |
| 创建/覆盖 Wiki | 创建新页面或完全覆盖已有页面 | 编辑（谨慎使用） |
| 局部替换 Wiki | 替换 Wiki 页面中的特定文本 | 编辑（谨慎使用） |
| 重命名 Wiki | 重命名页面并自动更新关联链接 | 编辑（谨慎使用） |
| 删除 Wiki | 删除页面并自动清理关联死链 | 编辑（谨慎使用） |

> 注意：Wiki 编辑类工具会直接修改 Wiki 内容，建议只在需要时开启。启用后工具面板会显示危险操作警告。

### 数据分析工具

| 工具 | 说明 |
| --- | --- |
| 数据分析 | 理解 CSV/Excel 数据文件，生成 SQL 查询并执行统计分析 |
| 查看数据元信息 | 查看数据表结构、字段含义、数据类型 |

### 工具选择建议

| 场景 | 推荐工具组合 |
| --- | --- |
| 通用问答助手 | 思考 + 制定计划 + 关键词搜索 + 语义搜索 |
| 深度研究助手 | 上述 + 查看文档分块 + 查询知识图谱 + 获取文档信息 |
| Wiki 知识库 | 思考 + 制定计划 + 搜索 Wiki + 阅读 Wiki 页面 + 精读源文档 |
| 数据分析助手 | 思考 + 查看数据元信息 + 数据分析 + 查询数据库 |

> 提示：工具越多，每次对话传给模型的工具定义就越多，token 消耗也越大。建议根据实际场景选择必要的工具。

## 技能 Skills

技能（Skills）是遵循渐进式加载模式的模块化能力扩展单元。每个技能以独立目录的形式存在，包含技能定义文件（SKILL.md）和可选的脚本、参考文档等资源。

### Skills 的三级加载机制

| 层级 | 内容 | 加载时机 |
| --- | --- | --- |
| 元数据 | 技能名称和描述 | 启动时发现并缓存，始终可用 |
| 指令 | SKILL.md 正文（专业领域指令） | Agent 对话中需要该技能时按需加载 |
| 资源 | 脚本、模板等额外文件 | Agent 执行具体任务时按需读取 |

### 预装技能

睿阁内置了以下预装技能：

| 技能 | 说明 |
| --- | --- |
| 引用生成器 | 自动生成 APA、MLA、Chicago 等规范引用格式 |
| 数据处理器 | 数据分析、统计计算、格式转换，支持 Python 脚本执行 |
| 文档协作 | 引导用户通过结构化工作流程共同编写文档 |
| 文档分析器 | 深度分析文档结构和内容，提取关键信息 |
| 互动课程生成器 | 将 RAG 检索结果转换为互动课程 |

### 使用方式

在对话中，用户可以通过 `@` 提及方式引用特定技能。被引用的技能名称会随请求发送到后端，后端根据智能体的技能配置决定加载哪些技能的指令注入到 Agent 的上下文中。

> 提示：技能依赖后端沙箱环境。沙箱未启用时，技能功能不可用。技能指令会注入到 Agent 的系统提示词中，增加每次对话的 token 消耗。

## 检索策略

检索策略控制智能体在回答用户问题时如何从知识库中查找相关内容。以下参数影响检索的召回率和精度：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 向量召回数量 | 10 | 向量检索返回的最大结果数量，建议 10-20 |
| 关键词阈值 | 0.3 | 关键词检索的最低匹配分数，过高会减少召回，过低会引入噪音 |
| 向量阈值 | 0.5 | 向量检索的最低相似度阈值 |
| 重排数量 | 5 | 重排序后进入答案生成的文档数量 |
| 重排阈值 | 0.5 | 重排序阶段的最低得分阈值 |

### 查询扩展

查询扩展是快速问答模式下的一项默认开启的能力。当初始检索结果较少时，系统会自动对用户问题进行本地文本处理（不消耗 LLM 调用），生成多个查询变体并行检索，从而提升召回率。

扩展方法包括：提取关键词、提取引号短语、按分隔符拆分、去除疑问词。最多生成 5 个查询变体。

### FAQ 优先策略

当知识库中包含 FAQ 类型时，可启用 FAQ 优先策略：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 启用 FAQ 优先 | 开启 | FAQ 答案将优先于普通文档被引用 |
| 直接回答阈值 | 0.9 | 问题与 FAQ 相似度超过此值时，直接使用 FAQ 答案 |
| FAQ 分数加权 | 1.2x | FAQ 结果的相关性分数乘以此系数，使其排序更靠前 |

## 联网搜索

智能体可以配置联网搜索能力，让智能体在知识库之外还能获取实时互联网信息。适合回答时效性问题（如新闻、最新政策）或知识库未覆盖的领域。

联网搜索配置参数：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 网络搜索 | 关闭 | 启用后智能体可以搜索互联网获取信息 |
| 搜索引擎 | 系统默认 | 可为不同智能体指定不同的搜索引擎 |
| 最大搜索结果数 | 5 | 每次搜索返回的最大结果数量 |
| 自动抓取页面内容 | 关闭 | Rerank 后自动抓取排名靠前的网页完整内容，提升回答质量 |

> 注意：联网搜索会产生额外的搜索 API 调用成本。

## 多模态能力

智能体支持在对话中处理图片和音频等多媒体内容：

| 能力 | 说明 |
| --- | --- |
| 图片上传 | 用户可在对话中上传图片，由 VLM 视觉语言模型理解图片内容 |
| 附件图片理解 | 对图片型 PDF/PPT 等扫描件，用 VLM 进行 OCR 识别 |
| 语音上传 | 用户可上传音频文件，系统使用 ASR 模型自动转录为文字 |

## 常见问题

**Q1：快速问答和智能推理模式怎么选？** 大多数知识库问答场景使用快速问答即可，响应速度快、配置简单。如果需要工具调用、多步推理、数据分析等高级能力，选择智能推理模式。

**Q2：智能体类型预设选错了可以改吗？** 可以。在智能体设置中可以随时更换预设或切换到自定义模式。

**Q3：工具越多越好吗？** 不是。工具越多，每次对话传给模型的工具定义越多，token 消耗越大，且可能影响模型选择工具的准确性。建议根据实际场景选择必要的工具。

**Q4：联网搜索的结果和知识库的结果会冲突吗？** 不会。系统会将联网搜索结果和知识库检索结果统一通过 Rerank 模型排序，按相关性输出最终结果。

**Q5：技能和工具有什么区别？** 工具是智能体的固定能力（如搜索、查询），技能是可插拔的专业领域模块（如数据分析、文档协作），通过 `@` 提及按需加载。

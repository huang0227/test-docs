## 概述

全局设置集中管理睿阁的账户偏好、企业信息、AI 模型和基础设施配置。通过用户信息区的「全部设置」按钮进入，弹窗尺寸 1080×780px，左侧导航栏 + 右侧内容区布局。

本文按分组介绍各设置页面的功能和操作方式。

---

## 前置条件

- 已登录睿阁并进入主工作区。
- 部分设置项需要管理员或所有者权限。

---

## 操作步骤

### 进入设置

1. 在左侧侧边栏底部找到用户信息区。
2. 点击用户头像/名称区域展开面板。
3. 点击「全部设置」按钮，打开设置弹窗。

**左侧导航分组与权限**：

| 分组 | 菜单项 | 普通成员 | 企业管理员 | 所有者 |
|------|--------|:---:|:---:|:---:|
| 账户 | 常规设置 | ✅ | ✅ | ✅ |
| 账户 | 用户信息 | ✅ | ✅ | ✅ |
| 账户 | 修改密码 | ✅ | ✅ | ✅ |
| 企业 | 企业信息 | ❌ | ❌ | ✅ |
| 企业 | 管理员管理 | ❌ | ❌ | ✅ |
| 企业 | 消息管理 | ❌ | ✅ | ✅ |
| 模型 | 模型管理 | ❌ | ✅ | ✅ |
| 模型 | Ollama | ❌ | ✅ | ✅ |
| 数据与扩展 | 向量数据库引擎 | ❌ | ✅ | ✅ |
| 数据与扩展 | 解析引擎 | ❌ | ✅ | ✅ |
| 数据与扩展 | 存储引擎 | ❌ | ✅ | ✅ |
| 数据与扩展 | 网络搜索 | ❌ | ✅ | ✅ |

## 账户设置

### 常规设置

| 设置项 | 控件 | 说明 |
|--------|------|------|
| 主题模式 | 下拉选择 | 浅色 / 深色 / 跟随系统，选择后立即生效 |
| 界面字体 | 下拉选择 | 系统默认 / 微软雅黑 / Times New Roman / 通用无衬线，下方有实时预览 |
| 代码字体 | 下拉选择 | 系统默认 / Consolas / Cascadia Code / 通用等宽，下方有实时预览 |
| 开启记忆功能 | 开关 | 开启后系统记录对话历史并在后续对话中自动回忆，仅 Neo4j 可用时可操作 |

### 用户信息

只读展示以下账户信息：
- 用户 ID（唯一标识）
- 用户名（登录用户名）
- 邮箱（注册邮箱）
- 注册时间（YYYY/MM/DD HH:mm 格式）

### 修改密码

> 注意：修改密码后当前登录状态将失效，提交成功后需要重新登录。

| 字段 | 说明 |
|------|------|
| 当前密码 | 必填 |
| 新密码 | 必填，8-32 个字符，包含字母和数字 |
| 确认新密码 | 必填，需与新密码一致 |

## 企业设置

### 企业信息

| 字段 | 说明 | 权限 |
|------|------|------|
| 企业 ID | 只读展示 | 所有人可见 |
| 企业名称 | 最多 64 字，回车保存/Esc 取消 | 仅所有者可编辑 |
| 企业描述 | 最多 512 字，Ctrl/Cmd+Enter 保存 | 仅所有者可编辑 |
| 企业业务 | 只读展示（仅在有值时显示） | 所有人可见 |
| 创建时间 | 只读展示 | 所有人可见 |

### 管理员管理

**角色权限说明**：

| 角色 | 管理管理员 | 修改企业配置 | 配置模型/向量库 | 创建编辑知识库和智能体 | 查看企业内容 |
|------|:---:|:---:|:---:|:---:|:---:|
| 所有者（Owner） | ✅ | ✅ | ✅ | ✅ | ✅ |
| 管理员（Admin） | ❌ | ❌ | ✅ | ✅ | ✅ |

**邀请管理员**（仅所有者）：
1. 点击「邀请管理员」按钮。
2. 搜索用户名或邮箱（输入至少 2 个字符）。
3. 选择用户后确认发送邀请。
4. 被邀请人在站内接受后成为管理员。

**审计日志**：点击「审计日志」按钮打开右侧抽屉，查看操作审计记录（成员变更与访问拒绝事件），按时间倒序展示。

**管理员列表**：支持搜索成员、移除管理员（仅所有者，不可移除自己）。

**待接受邀请列表**：展示已发出但未被接受的邀请，支持撤销操作。

### 消息管理

- **启用消息索引**开关：开启后新对话消息自动索引到知识库，支持向量搜索。
- **Embedding 模型**：选择用于消息向量化的模型。已有索引消息时锁定不可更换。
- **索引统计**：显示已索引消息数量。

## 模型设置

### 模型管理

按类型分 Tab 展示：全部 / 对话 / Embedding / ReRank / 视觉 / 语音。

**模型卡片**：显示模型名称、类型徽章、供应商、操作菜单（编辑/复制/删除）。

**添加/编辑模型**：

| 区域 | 配置项 |
|------|--------|
| 基本信息 | 模型类型（chat/embedding/rerank/vllm/asr）、来源（local Ollama / remote API） |
| Remote API 配置 | 服务商选择、模型名称、显示名称、Base URL、API Key、自定义请求头 |
| 高级选项 | 向量维度（embedding）、支持视觉/多模态（chat）、思维链控制（chat）、后台并发上限 |

**支持的服务商**：OpenAI、Azure OpenAI、阿里云 DashScope、智谱 BigModel、OpenRouter、Google Gemini、硅基流动、火山引擎、DeepSeek、腾讯混元、腾讯云 LKEAP、MiniMax、小米 MiMo、GPUStack、魔搭 ModelScope、七牛云、月之暗面、百度千帆、NVIDIA、Novita AI、自定义 OpenAI 兼容接口等。

> 提示：添加远程模型时可点击「测试连接」验证 API 连通性。

### Ollama

管理本地 Ollama 服务：
- **服务状态**：自动检测（可用/不可用/未检测）。
- **服务地址**：默认 http://localhost:11434，如需修改请在 .env 配置文件中设置。
- **下载新模型**：输入模型名称（如 qwen2.5:0.5b）下载。
- **已下载的模型**：展示已安装的模型列表（名称、大小、修改时间）。

## 常见问题

### Q1：普通成员能看到哪些设置？

普通成员只能看到「账户」分组下的常规设置、用户信息和修改密码。企业相关、模型和数据扩展设置仅管理员及以上角色可见。

### Q2：添加模型时报错「SSRF validation failed」怎么办？

ReKnow-Core 内置 SSRF 安全校验。需要在 engine 容器的环境变量中添加 `SSRF_WHITELIST_EXTRA`，将模型服务的域名加入白名单（逗号分隔）。修改后需重启 engine 容器生效。详见 [常见问题](/zh/faq)。

### Q3：Ollama 服务检测不到怎么办？

确认 Ollama 已在本地运行。默认服务地址为 http://localhost:11434，如需修改请在 .env 配置文件中设置 DOCREADER_ADDR 等环境变量后重启服务。

### Q4：向量数据库创建后能更换引擎类型吗？

不能。创建后引擎类型和连接配置不可修改，如需更换请删除后重新创建。

### Q5：存储实例删除失败怎么办？

删除前需满足以下条件：非环境变量来源、非工作区默认实例、无知识库绑定、无活跃资源关联。检查不满足的条件后逐一解除关联。
